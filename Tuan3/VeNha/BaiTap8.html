Heroes of JavaScript and HTML

Heroes of JavaScript and HTML is a “Heroes of Might and Magic”-like game, but for code nerds.

Currently the game has only four hero types:

Front-end Developer

Builds interfaces for users.

💻

Mobile Developer

Creates mobile applications.

📱

Web Developer

Develops web solutions.

🌐

QA Engineer

Tests software quality.
